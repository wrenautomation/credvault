# Contributing

Fork it, change it, send a pull request. The license (PolyForm Shield 1.0.0, LICENSE.md) lets you use, change and share this code for any purpose except a product that competes with Wren Automation.

When you send a change, you agree to these terms:

- The change is your own work, or you have the right to send it.
- You license the change to William Jin under the Apache License 2.0, so it can ship under this repo's license and any later one.

Before you commit, run `pnpm lint && pnpm typecheck && pnpm test`. Never commit secrets, real account data or personal data.
